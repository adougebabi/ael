权威来源：`Task.Board` 与 `Service.Next` 决定主分组和下一动作；有效 Attempt 的租约决定执行者；`CurrentEvidence` 同时核对候选、定义、计划及检查配置。完成结果来自 `Task.Result`，发布必须有实际交付回执。工作进展采用实际提交、检查和 `work_progress`，不把 heartbeat / Updated 当作进展。

知识有效状态沿用 `ReadAll` 及来源账本，引用沿用 definition.knowledge / supplied basis / record.tasks / superseded_by。最小补齐为只读任务摘要、知识分页与按需正文、基于显式引用的演进投影、迁移影响汇总，不建立新状态机。资料增加可选的 `summary`、`rationale`、`occurred_at` 元数据用于明确记录；缺失时正文摘录、未记录原因、日期未确认均如实显示，不改写旧资料。

未提供的事实不推断：未配置/未探测的执行器能力、未记录的历史发生日期、未有回执的发布、没有明确关系的变化因果、无法确定影响的迁移告警。运行库与大测试产物均使用项目外隔离目录。
