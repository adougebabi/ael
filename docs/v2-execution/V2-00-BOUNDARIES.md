# V2-00：四个实现边界

- **Epic / 叶子任务：** Epic 保存范围、拆分、验收映射及最终集成目标；实际业务修改由可独立验证的叶子任务承担，Attempt 仍只是执行记录。组织关系不等同于依赖，父级完成需要整体验收。
- **Local / Remote 权威：** Local 继续使用现有本地领域服务与运行数据库；Remote 的任务、调度和证据元数据以中心 Server 为唯一权威。Git 项目文件是代码及现行规范的来源，Server 保存来源与不可变快照，不让旧本地记录覆盖远程运行态。
- **Server 与执行：** Server 不运行任务携带的任意 shell，不访问客户端绝对路径，也不保存模型凭据；实际工作由各客户端授权的本地 Runner 在自己的工作区完成。
- **任务 / 证据版本：** 验收与证据绑定可核对的候选、定义和计划修订及相关检查配置，候选通过仓库、提交与必要内容清单/哈希确定；分支名、时间或客户端路径不足以证明候选一致。变更需重新检查适用性，不能把旧结果当作当前授权。

此文件登记边界，并不声称这些 V2 行为已经实现；V2-00 不做迁移或建立远程服务。
