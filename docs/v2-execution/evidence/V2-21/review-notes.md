# V2-21 复核与实现决定

三轮限定只读复核分别检查 Local 导出、中央导入及最终恢复边界。已保留发现对应的失败和通过用例。

- 旧相对附件从绑定 CandidateWorkspace 读取，输入图片、交付回执、历史哈希及规范快照参与盘点。已保存对象可在源文件后来缺失时用于原计划恢复。
- 历史终态父树先建立普通任务关系，再恢复原终态，optional 成员和里程碑保留。未完任务暂停，计划修订、非验收检查点、失败记录与预算保留，verify/delivery 从新实施或集成建立证据。
- 来源 ID 共用同一验证规则。单文件 10 MiB、请求 2 MiB 的已有限制在冻结前核对。旧媒体通过相同字节验证后提供预览，其余历史字节使用下载对象保存。
- 中央回滚对账包含任务哈希编码的计划锁。相关 metadata 在冻结后拒绝写入，完成回执再次核验范围。不存在批次时使用终止标记，未激活批次使用初始范围基线，迟到请求受到拒绝。未完成上传可按原键取消，冻结分块在写文件前拒绝。
- 迁移复用项目 executor 权限，控制操作校验原导入者或管理员 session。reader/reviewer 保留原权限边界。身份、成员权限、候选、租约及证据门禁沿用既有规则。
- 完整原 Task 与 RecordHistory 在中央保存，原 SQLite 事件日志和运行元数据位于私有恢复备份。有效 token、lease、PID、workspace 和模型 session 操作值从中央快照中清除。备份包含旧本地授权数据，保存在项目外私有目录。
