## 实施内容

1. 复用检查结果入口，定义/落实 Finding：任务/检查/候选、规则、路由与定位、期望/实际、复现步骤、影响、来源和证据。UI 要真实截图，UX 要真实步骤/trace/录屏等适用证据。
2. 外部 Bot 自行选择浏览器、模型与检查工具，CLI 只接收结构化报告和附件；不新建 AEL 自带扫描进程或模型服务。
3. 模型建议、人工判断和确定性执行报告保留来源；缺证据显示待补证/无法验证，不凭自信分完成门禁。
4. 用稳定定位、规则及明确候选关系归并重复发现，保留每次出现；不同问题不按标题相似强行合并。
5. 问题列表能筛选、定位证据、关联任务；扫描报告完成与受验产品通过分开。
