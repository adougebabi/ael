## 实施内容

1. 父任务保存最终集成候选和整体验收覆盖；叶子证据绑定其受验候选，不能自动证明合并后的候选。

3. 只有所有必要范围已覆盖、必要叶子达标、整体验收和交付目标满足时父可关闭。取消必要任务、删除验收项需受控范围修订。

5. 小任务没有父层时保持简单；只验收 report 交付和 verified 产品验收分开，不能混淆。
