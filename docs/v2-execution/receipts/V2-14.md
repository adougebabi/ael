## 实现与边界

- StandaloneApp 保留登录、项目/成员/令牌和原始依据附件入口。选项目后进入共用工作台。
- 项目 Dashboard GET 入口每次核对真实角色，任务采用 RemoteTaskView 脱敏。公共协作字段仅保留声明工作区，旧本机路径、token、PID 和私有会话字段不重新公开。
- 同步游标绑定 project、Server 实例与事件水位。变化和重连触发权威摘要重读，页面沿用请求序号，项目/会话代次拒绝旧响应，导航位置按会话与项目隔离。
- 责任状态、最后上报、阶段与未知宿主状态分别呈现。alias/machine 是客户端声明。责任记录使用 Attempt，Agent 模型会话未声明时明确显示未声明。
- 暂停/取消使用原 task mutation、真实角色、CSRF、expected_revision、幂等键。检查仍由外部执行者报告。
- 中央规范来自 finalized 且哈希一致的 context 原件。共享分页与演进逻辑，保留结构化知识的原始 source。多版本冲突提供明确选择。历史正文链接绑定 source hash、context 和目标 hash。
