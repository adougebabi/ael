# V2-08 · 独立 Server 与远程身份边界

- 开始基线：本地 `main` 的 `357ba18`（V2-07 检查点）。独立 Server 的存储和 HTTP 实现位于 `internal/server/standalone_*`，命令行入口为 `cmd/ael/standalone.go`，嵌入页面为 `web/src/StandaloneApp.vue`；本地单项目 Dashboard 保持原入口。
- 交付：`server bootstrap --data-dir DIR --username NAME --password-stdin` 在专用本机目录初始化首个管理员；`server start --data-dir DIR` 默认仅监听 loopback。SQLite 和附件根位于该目录，不需要业务 checkout。管理员可在浏览器注册项目、创建成员并授予执行者、验收者或只读者角色，签发和撤销项目范围的 Agent 令牌。当前远程路径只覆盖登录、项目和授权管理，不接收客户端文件路径或执行任务命令。
- 安全边界：密码使用随机盐和 Go 标准库 PBKDF2-HMAC-SHA-256；会话与令牌仅存摘要。浏览器会话使用 HttpOnly/SameSite cookie、Origin 和 CSRF 校验，账号或来源的登录尝试受限；只有显式配置的代理才可提供转发协议和客户端链。所有变更要求协议版本 1。页面在会话失效或跨标签账号变化时清除原账号数据。
- 数据：独立 Server 在自己的 SQLite 中建立账户、项目、成员、会话和令牌表；不迁移或覆盖现有本地项目运行库。数据目录拒绝已有未标记内容、数据库及辅助文件的符号/硬链接；macOS 拒绝 ACL，Linux 限定已识别本地文件系统。容器叠加层的底层存储仍须由部署者确认不是网络挂载。
