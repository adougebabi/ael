## 实现

- version --check 分别报告 CLI、项目入口和 Server 的版本/协议。旧绑定缺省为 API/Skill 1，旧 Server 没上报版本时明确标为 unreported。活动会话可声明其已取得的协议，不支持声明在通信前拒绝。读写均检查服务协议，离线缓存保持非权威，认证/项目权限和原责任门禁继续有效。
