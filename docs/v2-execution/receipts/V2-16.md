## 实现

- EvidenceComparison 提供明确基准/实际选择、并排、缩放、叠加、问题定位、来源和中央原件下载。基准初始为空，图片按中央 ID 读取。发现中的页面、视口、环境、定位、原始报告和交互资料可追溯。
- reviewer/admin 浏览器会话通过 POST `/api/v1/projects/ID/reviews` 提交 review_result、review_pending、review_confirm、review_resume。actor 从会话生成，普通令牌及只读会话受到拒绝。沿用逐检查裁定，每次请求明确一项检查和一组版本。
- 共享 validateHumanReview、ReviewAccess、原意见确认/恢复规则及 submitTx 状态机。中央事务同时保存短期无进程人工 Attempt、Evidence、流转与幂等回执，拒绝时整体回滚。
- 正式结论绑定请求时状态、候选、定义、计划和检查配置，核验 finalized 字节、hash 及任务/候选关联。原请求重放返回原回执。必要检查与交付目标继续参与门禁。
- 比较所选图片的 ID、hash、候选、来源和上传者进入正式证据或意见。应用意见时再次验证其比较输入。旧候选意见显示过期并清除旧意见关联，输入与图片选择保留，重新审阅后可记录新观察。
- 草稿按项目、会话、任务和检查隔离。候选/修订冲突、丢失响应、上传或读取失败保留输入。项目身份读取失败时等待恢复读取，慢于轮询周期的图片请求可正常完成。

主要代码为 internal/core/remote_review.go、pending_human_review.go、review_readiness.go、verify.go、service.go，internal/server/remote_review.go、remote_dashboard.go、remote_project.go，以及 web/src/components/EvidenceComparison.vue、ManualReviewDialog.vue、FindingPanel.vue 和 remoteDashboard.ts。README、架构、远程文档及分发 Skill 已同步。
