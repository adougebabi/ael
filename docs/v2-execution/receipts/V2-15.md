## 交付

- `finding report/list/show` 为正式远程 CLI。report 复用 context 检查报告入口、版本/候选/身份/原件校验和 p.mutate 事务，并接入已有私有操作记录与 runner retry。
- Finding 按任务、检查配置、定义/计划版本、候选、规则、种类、路由与精确定位归并。标题不作为身份，每个报告新增不可覆盖的出现，原键重放返回原出现。
- 来源保存鉴权 actor 与 method/tool/version/run_id。human 类型要求具有验收/管理权限的登录会话。普通 token 无法伪装该来源。
- UI 缺截图、UX 缺交互证据、缺原始报告/期望/实际/复现/影响时标待补证。提供的原件需 finalized，候选与任务或合法引用匹配，实际字节/哈希可读。
- 最新 portable observation 决定诊断候选版本，旧候选不会继续标当前。原报告和每次出现保留原版本。
- 任务详情提供发现列表、筛选、出现详情、原始报告、截图、定位、受检版本和关联任务。复用现有原件预览与清理状态读取。
- 发现接收固定 gate_effect=none，Task/Next/CurrentEvidence 保持原验收职责。原报告任务交付和产品达标继续按其目标区分。
