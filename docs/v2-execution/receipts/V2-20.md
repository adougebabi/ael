## 实现与使用

单实例 Compose 使用固定 AEL/Caddy 镜像、独立数据/证书/备份卷、私网后端、私有 loopback health 与 HTTPS 入口。运维 operator 使用同一非特权 Server 镜像并禁用网络。客户端可显式保存公共 CA，普通请求、持久操作和责任通信共用标准证书链及主机名验证。

管理员 maintenance CLI 复用 session/CSRF 和 authorization.lock。drain 拒绝新领取，deadline 后拒绝受保护写入。quiesce 持久记录阶段，逐项目中断旧责任、清除 lease、保留 unknown workspace hold，原键可续跑且不重复处理代次。原回执继续可查，resume 后旧责任仍失效。

server backup/verify-backup/restore/migrate 覆盖根库、所有已注册项目库、配套投影和全部附件。SQLite 使用原 VACUUM INTO，一致维护点由既有授权独占栅栏保证。manifest 记录版本、数据格式和每文件 SHA/大小，恢复先验全量字节再变更空目标。恢复阶段意图可在相同输入下续跑，最终 marker 提交前拒绝服务。

格式 1 必须先停止旧服务并明确 --ack-stopped，再备份/迁移。格式 2 marker 在格式 2 写入前提交，真实旧程序拒绝打开。恢复支持新空卷继续挂载于历史 /data，重定位已知中央 outbox，核对私有权限、硬链接和 ACL。未知数据库布局与非空恢复目标明确拒绝。

代码位于 internal/server 的 maintenance、server_backup、server_restore、server_format、standalone_health，internal/core/remote_maintenance，internal/remote/tls，cmd/ael/server_*，packaging/compose 和两项正式验收脚本。完整操作见 docs/server-operations.md，README、架构、Skill、CLI help 与 Compose README/DESIGN 已同步。

## 数据与限制

恢复会清除旧浏览器 session 并撤销备份中的项目令牌。这是本次实现选择，管理员须重新登录并签发新令牌。账号、密码摘要、成员、任务树、规范、候选、发现、人工结果、历史回执和证据保留。旧 API 责任失效，宿主执行状态仍记 unknown。

格式迁移是明确的离线运维动作，--ack-stopped 依赖操作者已停止旧服务。运维 CLI 可持有本机数据权限，正常部署保持单实例。备份包含授权和身份数据，按私有数据保管。断电级持久性仍未实测。

同机 TLS/网络、进程中断和备份演练不代表实际多机验收。恢复没有宣称终止外部编译或 Agent。产物保持未发布，Oracle 与业务工程尚未操作。
