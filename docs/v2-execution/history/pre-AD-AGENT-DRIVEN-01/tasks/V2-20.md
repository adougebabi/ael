**目标：** 交付可在 Oracle 单机部署的服务，并验证数据恢复，不只是一个 Dockerfile。

## 实施内容

1. 提供 Docker Compose 及必要的二进制服务启动说明。Server 单实例、持久卷、健康检查、固定版本镜像/包；TLS 复用标准反向代理，可替换现有代理。
2. 默认不暴露无认证公网端口；初始化管理员凭据以安全交互/受限文件提供，禁用示例默认密码。明确防火墙、域名、资源和 CPU 架构核对步骤。
3. 提供 server upgrade/维护流程：停止新领取、等待或安全暂停活动执行、备份、数据库迁移、切版本、健康检查、恢复。不能把容器重启等同于数据升级成功。
4. SQLite 使用一致性备份；证据目录按清单和哈希配套备份，实际 restore 验证。数据库不兼容时禁止仅回退旧二进制，说明恢复快照及潜在数据边界。
5. 容量统计分 DB/WAL/附件/临时上传/日志/备份；可预览保留策略，保护进行中任务和未裁定问题的证据。
