# V2-08 · 独立 Server 与远程身份边界

**前置：** V2-07 已 DONE，且其回执存在。
**执行纪律：** 先读 `../00-EXECUTION-CONTRACT.md` 与 `../WORKLOG.md`，只实现本项；本项 DONE 后才读取下一任务正文。
**目标：** 中心服务能够安全启动，独立管理项目，不以某个客户端目录作为服务器根。

## 实施内容

1. 增加 server 运行模式和显式数据目录，嵌入现有 Dashboard。服务端 SQLite 及附件根位于持久卷；领域规则复用，不能直接把单项目本地 dashboard 原样暴露公网。
2. 项目注册与成员/令牌授权至少覆盖管理员、项目执行者、验收者、只读者；浏览器登录与 Agent Token 分离。令牌可撤销、服务端保存安全摘要。使用成熟库，不手写密码学。
3. 支持浏览器安全会话、CSRF/Origin 校验、登录节流和授权失败；反向代理 TLS 只信任配置的代理。默认 loopback，公网部署由后续明确配置。
4. 新增 API 协议版本和能力发现；不兼容客户端拒绝变更并给出更新指引。服务端不能根据请求中的任意路径访问文件或执行命令。
5. 实现管理 bootstrap/登录/项目查询这一条真实路径；不提前为所有远程模块搭空接口。

## 必须通过的本项验收

- [ ] 服务器在没有业务 checkout 的空目录启动；重启保留注册数据。
- [ ] 未登录不能读任务/证据；无权限项目不能通过猜 ID 访问。
- [ ] 浏览器可登录登出，Token 可撤销；已有本地模式正常。
- [ ] 请求不能通过伪造 executor 字段获得管理员权限。
- [ ] 认证前错误与日志不泄露数据库路径、令牌或密码。

## 边界

不部署 Oracle、不开放公网、不接收任意 shell。数据库同机，禁止网络挂载 SQLite。
