# 旧阻塞与验收的重新归属

这是用户明确变更产品职责后的测试映射，不是删断言换绿灯。保存旧版本、失败输出、替代条款与新测试 ID。只移除已经退出产品范围的能力要求；新支持路径中的缺陷必须修。

| 旧要求或失败 | 本次归属 | 新契约下验证什么 |
|---|---|---|
| AEL 启动 Agent 并监督编译/测试 | 远程默认路径移除 | 外部 Agent 调用 CLI；Server/CLI 不启动工程执行进程 |
| 同 UID Agent 不能读取自己的协作凭据 | 不作为 AEL 安全承诺 | 最小权限、身份不可伪造、可撤销、凭据不主动进入日志/任务上下文 |
| 主进程退出必须杀死所有脱组后代 | 不属于薄客户端职责 | 责任失效/未知状态如实记录；旧提交拒绝；不误报宿主进程已结束 |
| APFS 卸载、文件标志、自制沙箱 | 停止本轮研究 | 无客户端 Docker/沙箱前置也能完成协作 |
| 允许 make test 后阻止它间接运行任意 git push | 不在 AEL OS 管理范围；保留风险观察 | AEL 不执行 make 或 push；AEL 授权接口正确，实际远端发布由外部权限边界控制 |
| Server 回执后自动交付副本到原 checkout | 从远程默认路径移除 | CLI 不修改项目源码/自动合并；源码变化只由外部执行者做 |
| 两个远程正向测试因全局隔离门禁 503 | 需要修正入口，不可当预期失败永远保留 | 用真实通信主路径完成 claim/context/upload/submit/next；无 overlay |
| 身份跨项目越权、旧 fence 被接受 | 必须修复 | 撤销/过期/版本变更后有效业务写入拒绝 |
| 缺产物、错误哈希、旧候选也能通过 | 必须修复 | finalized 字节和实际候选/检查版本绑定，来源及覆盖完整 |
| 丢回执引起重复结果/下一任务 | 必须修复 | 查询已接受操作，重试幂等，不把重放当新授权 |
| 断网时静默转为本地第二套任务 | 必须拒绝 | 只保留待确认草稿/上传，不创建第二个运行权威 |
| 未知工作区写者自动被安全接管 | 不得声称已解决 | 相同工作区恢复受控；独立工作区交接明确选择，保留未知历史 |
| 日志任意编码完备脱敏 | 不作完备承诺 | 已知凭据基础防泄露保留；默认不上传整机/全部对话/凭据文件 |
| 所有子任务仅部分实现仍完成父任务 | 必须拒绝 | 已实施/已验收/已集成/已发布分开，父级必需范围仍完整 |

## 处理方式

1. 为每条被修改测试记录原意、退出范围的能力、新测试位置。原证据保留，不能宣布漏洞已修复。
2. 已明确撤下的远程托管模式测试可以归档为历史/实验，不再出现在“支持模式必需通过”套件；没有真实替代行为的必要正向测试不能随意挪走。
3. 保留稳定 Local Managed 原有回归；不因为用户采用外部 Agent 就删除旧用户数据或直接破坏原功能。
4. 禁止 `t.Skip`、恒真、overlay 或环境变量绕过仍属于当前职责的认证、版本、候选和证据检查。
5. 最终报告并列显示：新模式的结果、旧模式撤下的范围、未验证环境。不得只报一条“全绿”。
