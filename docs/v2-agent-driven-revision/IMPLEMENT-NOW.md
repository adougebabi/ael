## 本次明确的产品决定

Oracle 用 Docker 部署 AEL Server + Dashboard。Mac/云电脑已有 Agent 调用 AEL CLI/通信脚本处理领取、上下文、进度、证据、结果和下一动作。Agent 自己编码、编译、测试、截图、管理工作区和使用自己的宿主执行环境。

AEL 不启动 Agent、不管理其子进程、不建立强制任务容器、不自动复制/回写源码、不拦截任意本机命令，也不掌管模型/发布凭据。本地 Docker 可以推荐但不是产品通用准入条件。

AEL 仍管理规范、计划、任务树、协作权限、版本、证据、验收门禁、流转和可观测性，不退化成任意上传日志后就能手动标完成的系统。
