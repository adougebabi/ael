## 对 V2-00—11 的处理纪律

已完成能力不是无效成果。优先核对 V2-03/04/05/06/07/09/11 的外部 Agent 路径：

- 能否不启动 AEL 托管执行器，完成拆分、领取、上下文、进度、结果和下一动作？
- 必要的父级门禁、重复失败和证据一致性是否仍有效？
- 页面与命令是否错误承诺“进程已停”“执行环境已隔离”？

只有发现直接依赖旧托管模型的入口或断言，才在当前 V2-12 内做最小改动和回归。每项追加“本次边界核对结果/修正落点”，不改写历史 PASS，也不把未复验能力宣称为新契约已通过。

## 对 V2-13—23 的处理纪律

本包提供新的任务正文。只更新计划，不提前写其产品功能；编号和依赖顺序不变。达到对应任务时执行其实现与验收。

本次 V2-12 通过后先暂停。以后用户明确要求继续，才按修订后的 V2-13 开始。

## 非本次目标

不重新设计大任务领域、不重做页面、不换数据库、不新增模型 SDK、消息队列、强制客户端 Docker、容器监督服务或任意工作流编辑器。不把宿主控制能力重新藏进一个“可选适配器”作为本轮新工程。
