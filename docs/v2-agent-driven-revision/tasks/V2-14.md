# V2-14 · 统一 Dashboard 与协作状态可观测性

> 修订依据：AD-AGENT-DRIVEN-01。替代原同编号任务的冲突要求；不证明现有代码已实现。
> 当前实际执行位置仍为 V2-12。若本文件编号大于 12，本次只更新任务规范，不开工。

**前置：** V2-13 实际完成，回执存在。
**目标：** 一个地址看清两端任务、进度、真实卡点和证据，准确区分协议状态与宿主实际运行状态。
**纪律：** AEL 不自托管；本轮开发 WIP=1；已有代码优先复用；先实现、验证、修复、回执，再标 DONE。

## 实施内容

1. 复用 Server 登录、项目切换、父子工作台、规范/决策和演进页面，统一权威来源，不重做视觉。
2. 用有游标的轮询或轻量通知更新并从权威摘要恢复；断线显示 stale，重连补齐，不另造前端状态机。
3. 展示执行者别名、会话/机器、实际取得的责任、候选、最后联系和最近有效结果；无依据时不推断本机进程存活。
4. 待接手、待人工、环境阻塞、失败复核、责任失效和已报告的执行阶段分开。心跳不是已取得工程进展。
5. 暂停/取消操作明确其协作效果：撤销后续状态提交与推进，提示外部执行者停止；未经宿主回报不显示进程已终止。

## 必须通过的本项验收

- [ ] A14-01：两个外部客户端上报进度后同一 Dashboard 更新，无需 git pull 或查看另一台本地服务。
- [ ] A14-02：网络断开、消息乱序、Server 重启不会倒退已确认结果或假装任务完成。
- [ ] A14-03：父任务 → 子任务 → 检查证据 → 规范 → 返回，筛选与位置可恢复。
- [ ] A14-04：暂停/取消和失联时，任务责任状态、执行者最后上报与未知进程状态不混淆。
- [ ] A14-05：跨项目请求/缓存隔离，未经授权不可读；打包页面可真实操作。
